# 10086 混乱代码库

> 一个充满混乱美学的代码集合

## 内容

- `chaos.py` - 混乱计算器，支持表达式计算、记忆功能、随机生成器
- `web_chaos.html` - 混乱网页，字符雨特效 + 闪烁效果
- `chaos.sh` - 混乱shell脚本，随机emoji + 进度条 + ASCII艺术

## 使用

```bash
# 运行计算器
python3 chaos.py

# 运行shell脚本
bash chaos.sh

# 打开网页
open web_chaos.html
```

## 风格

- 代码能跑就行
- 变量名随缘
- 注释看心情
- 功能全靠缘分
